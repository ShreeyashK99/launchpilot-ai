## ⚡ Engineering Philosophy: 100% Vibe Coded & Agentic Development

This project was built from the ground up embracing the modern **"Vibe Coding" and Autonomous Agentic Development** paradigm:
- **Conductor Over Typist**: Rather than manually writing repetitive boilerplate syntax, the developer acts as a high-level system architect—directing autonomous AI agents, orchestrating state machines, and defining data schemas.
- **Agentic Velocity**: Rapidly turning product visions into deployed, type-safe Next.js 15 and Supabase architectures in hours rather than weeks.
- **Enterprise Verification**: Pairing high-speed AI code generation with rigorous automated testing (12/12 integration test suite), strict Zod schema validation, and Row-Level Security guardrails.

## 🌟 Key Features

- **Dynamic Full-Stack Synthesis**: Real-time generation of typed API routes, database schemas, and application architectures for any product domain (HealthTech, FinTech, CRM, Booking, Developer Tools).
- **Dual-Mode AI Engine**:
  - **Frontier Inference Mode**: Connects to the OpenCode API gateway (`https://opencode.ai/inference/v1`) supporting Claude 3.5 Sonnet, GPT-4o, and DeepSeek.
  - **Zero-Cost Heuristic Synthesis**: Autonomous fallback engine providing instant, offline, zero-latency code generation at ₹0 / $0 cost.
- **Production-Ready Code Standards**:
  - Next.js 15 App Router with Edge runtime configuration.
  - Supabase PostgreSQL migrations with relational foreign keys and Row-Level Security (`auth.uid()` policies).
  - Runtime request validation powered by Zod.
- **One-Click Spec Export**: Export generated Next.js routes and Supabase SQL migrations directly to your local workspace.
- **Automated Integration Testing**: Verified with a 12-case `test-suite.mjs` check covering HTTP validation, all 5 domain mappings, Zod/Edge generation assertions, page routes, and API latency.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ShreeyashK99/launchpilot-ai.git
cd launchpilot-ai
```

### 2. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
OPENCODE_API_KEY=your_opencode_api_key_here
OPENCODE_BASE_URL=https://opencode.ai/inference/openai/v1
```

### 3. Install dependencies and start the dev server
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
